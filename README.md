# web-irmarketing

Website institucional da iRMarketingStudio — agência criativa de João Pessoa/PB.

## Stack
- Next.js 14 (App Router) + React 18 + TypeScript
- Tailwind CSS (tokens da marca em `tailwind.config.ts`)
- GSAP + ScrollTrigger (animações em scroll) + Lenis (smooth scroll)
- React Three Fiber + drei (hero 3D, desktop only)

## Rodar
```bash
npm install
npm run dev
```

## Conteúdo
Todo o conteúdo do site vive em `lib/content.ts` (tipado).
- Números agregados (`stats`), `resultado` e `depoimento` dos cases estão
  vazios de propósito — quando a agência validar, preencha lá e as seções
  aparecem automaticamente com animação.
- Troque `marca.whatsapp` pelo número oficial.
